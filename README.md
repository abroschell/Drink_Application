A web-based drink ordering application built with HTML, CSS, and JavaScript. Users can customize their drinks by selecting different sizes, flavours, and extras, with the order total updating automatically as selections are made.

**Features:**
- Drink Customization: Select drink sizes, flavours, and additional options.
- Dynamic Pricing: Automatically updates the order total based on the selected options.
- Interactive Interface: Provides immediate feedback as users customize their orders.
- Input Validation: Checks user selections to help ensure orders are completed correctly.

**What I Learned**
Through this project, I gained experience with using JavaScript to create interactive web applications, updating webpage content dynamically based on user input. I got to practice implementing pricing calculations based on multiple selections, applying input validation and testing user interactions, and connecting HTML, CSS, and JavaScript to build a functional application.
